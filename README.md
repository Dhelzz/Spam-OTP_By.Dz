# Spam-wa_By.dz
===========================

*untuk spam wa dan sms for termux*
# *Pemkaian/pemasangan*
- *Import Githubnya dulu*
```bash
git clone https://github.com/Dhelzz/Spam-OTP_By.Dz
```
- *Masuk kedalam directory*
```sh
cd Spam-wa_By.Dz
```
- *Jalankan start.py atau Ketik ini di Terminal termux*
```bash
python Start.py
```
